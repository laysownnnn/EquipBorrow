# EquipBorrow

A system for tracking, borrowing, and returning shared equipment.

## Features

### Equipment Inventory & Catalog
- **Equipment Directory:** View all available items with details such as item name, category, serial/asset number, and current status (Available, Borrowed, Under Maintenance).
- **Search & Filtering:** Quickly find equipment by keyword, category, or availability status.
- **Condition Tracking:** Record item condition before checkout and after return to flag damaged or missing parts.

### Borrowing & Return Workflow
- **Borrow Requests & Checkout:** Submit requests or log equipment checkouts with borrower details, purpose, and expected return date.
- **Approval Management:** Review, approve, or decline pending borrow requests (for admins/custodians).
- **Return Processing:** Check items back in, update inventory availability automatically, and log return timestamps.

### Accountability & Notifications
- **Borrowing History:** View complete audit logs of who borrowed each item and when it was returned.
- **Due Date & Overdue Tracking:** Monitor upcoming return deadlines and highlight overdue equipment.
- **Role-Based Access:** Separate permissions for regular borrowers and administrators/equipment managers.
